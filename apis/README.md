# APIs

Each child directory represents one independently versioned API. Use a stable,
lowercase kebab-case identifier for its directory name.

| API | Description | Latest release |
| --- | --- | --- |
| [rostack_v1](rostack_v1/) | Discoverable read-only JSON API and event gateway | [2026-08-13 draft](rostack_v1/releases/2026-08-13/) |

Create new entries from `templates/api/` rather than adding release directories
directly under `apis/`.
